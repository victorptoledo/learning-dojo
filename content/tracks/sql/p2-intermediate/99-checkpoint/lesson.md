# Checkpoint 2: Intermediate

This checkpoint closes the **Intermediate** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): design the schema of a ticketing system whose
   constraints reject bad data, then report on it with a CTE or grouping and a window
   function.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Subqueries and Set Operations | When is a subquery correlated? Why is NOT IN dangerous? UNION or UNION ALL? |
| CTEs, Recursion and Views | What are the anchor and the recursive member? What does a view store? |
| Window Functions | rank or dense_rank? Why can WHERE not filter on a window function? What is the default frame? |
| Constraints and Keys | Which SQLSTATE means what? What does CHECK do with NULL? Which ON DELETE action fits? |
| Normalisation | Which dependency breaks 2NF, which 3NF? How do you model many-to-many? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
