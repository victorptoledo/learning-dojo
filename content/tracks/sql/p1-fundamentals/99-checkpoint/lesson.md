# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): four report queries and one change over a
   small library, with joins, NULL, aggregates, dates and an `INSERT ... SELECT`.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| The Relational Model | What do a primary and a foreign key enforce? Why `numeric` for money? |
| SELECT and WHERE | In which order do the clauses run? Why can WHERE not use a SELECT alias? |
| NULL | What does WHERE do with UNKNOWN? Why does NOT IN return nothing when the list has a NULL? |
| Joins | Where does a condition on the optional table go in a LEFT JOIN? What is fan-out? |
| Aggregation | WHERE or HAVING? What does count(column) skip? |
| DML | What does an UPDATE without WHERE do? How do you upsert? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
