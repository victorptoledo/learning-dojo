# Accessible Tabs: ARIA, Keyboard and Focus

Tabs have no native HTML element, so you build them from buttons and ARIA. This kata
implements the WAI-ARIA tabs pattern with automatic activation: roles and relationships, a
roving tabindex, arrow keys, Home and End, and disabled tabs. The tests find everything by role
and drive it with the keyboard, exactly as a screen-reader user would. Press **Enter** to
create the kata folder.
