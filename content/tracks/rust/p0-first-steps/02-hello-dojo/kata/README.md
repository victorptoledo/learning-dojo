# Hello, Dojo

Implement `greet(name)` in `src/lib.rs`.

- `greet("Ferris")` returns `"Welcome to the dojo, Ferris!"`.
- Surrounding spaces are ignored: `greet("  Ferris ")` gives the same greeting.
- An empty or blank name greets a stranger: `"Welcome to the dojo, stranger!"`.

Hints: `str::trim`, `str::is_empty` and the `format!` macro.
