# Greeting Drill

Practice for *Hello, Dojo*. Implement the three functions in `src/lib.rs`. Each one reads
a `&str` and returns a new, owned `String`.

1. `shout(name)` returns `name` in capitals followed by `!`: `"ada"` → `"ADA!"`.
2. `initials(full_name)` returns the first letter of each word, in capitals:
   `"grace brewster hopper"` → `"GBH"`. Extra spaces do not matter; a blank name gives `""`.
3. `echo(word, times)` repeats `word` `times` times, separated by single spaces:
   `("ha", 3)` → `"ha ha ha"`. Zero times gives `""`.

Save a file to run the checks. Passing gives practice XP; it does not change the kata.
