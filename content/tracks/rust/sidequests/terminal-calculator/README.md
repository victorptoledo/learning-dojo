# Sidequest: Terminal calculator

Build `calc`, a command-line calculator, from an empty `main`. You decide how the code is
organised: a tokenizer, a parser, an evaluator, enums for tokens and errors, modules... The
dojo only checks what the program **does**: its contract tests run the `calc` binary and read
its output and exit code.

- Edit `src/main.rs` (and add any modules you like). Keep the package name `calc`.
- Run it yourself with `cargo run -- "1 + 2"`.
- The project has no dependencies and the checks run offline: use the standard library only.

When you are done, `[A]` in the dojo copies a review prompt: ask an AI about your design.
