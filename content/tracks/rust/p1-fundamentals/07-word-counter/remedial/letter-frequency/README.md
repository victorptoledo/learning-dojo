# Letter Frequency

Practice for *Word Counter*. Implement the two functions in `src/lib.rs`.

1. `letter_counts(text)` counts each letter, ignoring case and everything that is not
   alphabetic. The most frequent letter comes first; letters with the same count are in
   alphabetical order. `"banana"` → `[('a', 3), ('n', 2), ('b', 1)]`.
2. `unique_words(text)` returns the distinct words, lower-cased, with leading and trailing
   punctuation removed, sorted alphabetically. Pieces that are only punctuation are not words.
   `"The cat, the HAT."` → `["cat", "hat", "the"]`.

Save a file to run the checks. Passing gives practice XP; it does not change the kata.
