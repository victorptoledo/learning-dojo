# Customer Specs

A customer repository grew one finder per business question, and a second class repeats the
same conditions as SQL with values glued into the text. You will turn the conditions into a
sealed family of **specification** records with `and`, `or` and `not`, then write two
interpreters: one that answers a spec in memory and one that renders it as a parameterised
SQL `WHERE` clause. Press **Enter** to create the kata folder and open it.
