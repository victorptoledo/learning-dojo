# Checkpoint 3: Advanced

This checkpoint closes the **Advanced** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): an enrolment service with static maps, an
   inline parser for a 2006 gradebook and five rules in one `if` ladder becomes a use case
   behind **ports**, with **repositories**, **specifications**, an **anti-corruption layer**
   and a **composition root**.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Repository, Unit of Work and Data Mapping | Is the repository's interface in domain terms? What does a unit of work promise? |
| Dependency Injection and Inversion of Control | Where is the composition root? Why is a service locator worse than a constructor? |
| Specification and Strategy as Functions | When is a `Predicate` enough, and when does a rule deserve a name? |
| Customer Specs (kata) | How do two interpreters read the same specification? |
| Ports and Adapters | Which side owns the port? What does an anti-corruption layer keep out? |
| Hexagonal Transfer (kata) | What may the domain mention, and what only the adapters? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
