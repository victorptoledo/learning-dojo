concept: "Adapter, decorator, proxy and facade"
from_way: "Deep subclass chains like `LoggingBufferedTransactionalUserService`, five levels down, and SDK types leaking into every service."
native_way: "An adapter per third-party API behind an interface you own; decorators that wrap the same interface and stack at wiring time; proxies generated by Spring; facades such as JdbcTemplate."
sensei_tip: "The Gang of Four's motto is 'favour composition over inheritance'. Decorator is its textbook example, and java.io is a decorator museum: count the wrappers in `new BufferedReader(new InputStreamReader(new GZIPInputStream(in)))`."
---

| Java | Pattern |
| --- | --- |
| `InputStreamReader`, `Arrays.asList` | adapter |
| `BufferedInputStream`, `Collections.synchronizedList` | decorator |
| `java.lang.reflect.Proxy`, Spring `@Transactional` beans | proxy |
| `Collections.unmodifiableList` | protection proxy |
| `JdbcTemplate`, `RestClient` | facade |
