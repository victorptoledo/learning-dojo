# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): price a shop order with records that validate
   themselves, a sealed hierarchy of discounts, `switch` patterns and collections.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Modern Syntax | When is `var` a good idea? What makes a switch expression exhaustive? |
| Records | What does a record generate? Where do I validate? How do I keep a list component immutable? |
| Sealed Types and Patterns | Why no `default`? In which order do guarded cases go? |
| Collections | `List.of` or `new ArrayList`? `merge` or `computeIfAbsent`? Which map keeps keys sorted? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
