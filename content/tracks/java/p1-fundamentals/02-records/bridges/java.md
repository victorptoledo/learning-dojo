concept: "Value classes without boilerplate"
from_way: "Private final fields, a constructor, getters, equals, hashCode and toString written by hand, or generated by Lombok's @Value."
native_way: "`record User(String name, int age) {}` declares a complete immutable value type; checks go in the compact constructor."
sensei_tip: "Replace @Value and @Data DTOs with records first: it is the change with the most lines removed and no behaviour change."
---

| Java 8 / Lombok | Record |
| --- | --- |
| `@Value class User { String name; int age; }` | `record User(String name, int age) {}` |
| `user.getName()` | `user.name()` |
| Validation in the constructor | Compact constructor `User { ... }` |
| `Collections.unmodifiableList(new ArrayList<>(list))` | `List.copyOf(list)` |
| `toBuilder()` / setters | `withName(...)` methods returning a new record |
