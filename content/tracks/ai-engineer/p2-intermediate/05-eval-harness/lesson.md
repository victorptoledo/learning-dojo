# Eval Harness: Scorers, Judges and a Regression Gate

The asset that outlives every prompt and model is the evaluation: a golden set, the scorers and
the rule that decides whether a change ships. You build a small harness: code-based scorers, an
LLM-as-judge scorer against a fake judge model, reports per tag and a baseline comparison that
blocks regressions. Press **Enter** to create the kata folder and open it.
