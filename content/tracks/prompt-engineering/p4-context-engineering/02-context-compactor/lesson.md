# Context Compactor: A Long Conversation in a Budget

Keep a coding agent's conversation within its token budget with the techniques from the lesson,
cheapest first: clear old tool results, then compact older turns into a summary, while every
tool call keeps its result and the user's pinned task is never summarised away. Durable notes
live outside the history and go into the system prompt. Press **Enter** to create the kata
folder and open it.
