# Type Utilities: Programming with Types

A kata with no runtime code at all: write ten utility types (`DeepReadonly`, `PickByValue`,
`OptionalKeys`, `UnwrapPromise`, `Getters`, `Merge`, `RouteParams`, `PathKeys`, ...) with
mapped, conditional and template literal types. Every test is a type-level test. Press
**Enter** to create the kata folder and open it.
