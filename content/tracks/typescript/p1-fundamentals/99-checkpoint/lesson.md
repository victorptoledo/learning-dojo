# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): a ledger that parses lines into a `Result`
   union, stores readonly transactions in a class with a private map, and builds reports.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Types and Structural Typing | When is a value assignable to a type? Why does a fresh object literal fail where a variable passes? What does `as` check at runtime? |
| Unions and Narrowing | How do you narrow `unknown`? What does `assertNever` buy you? When is `??` right and `\|\|` wrong? |
| Interfaces and Classes | `interface` or `type`, and why? What is really private, `private` or `#`? Why no parameter properties? |
| Generics | Which type parameter relates input and output? What do `K extends keyof T` and `T[K]` give you? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
