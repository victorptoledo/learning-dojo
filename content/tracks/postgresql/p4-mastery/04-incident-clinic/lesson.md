# Incident Clinic: Vacuum Blockers, Exhausted Sequences and Top Queries

The last kata of the track is a week on call: find the sessions that stop VACUUM, catch the
sequences that are about to run out, rank the statements that burn the most server time from a
pg_stat_statements export, and widen an integer key before inserts start failing. Press
**Enter** to create the kata folder and open it.
