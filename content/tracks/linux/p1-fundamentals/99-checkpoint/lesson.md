# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): an inventory of a directory tree, built from
   `find`, pipelines, arithmetic and permission tests.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| The Shell and the Filesystem | Who expands `*.log`? Where do configuration and logs live? How does bash find a command? |
| Files and Links | What is an inode? What happens to a symbolic link when its target goes away? |
| Streams and Pipes | Why `sort` before `uniq -c`? What does `2>&1` copy, and when? What does grep return with no match? |
| Permissions | What do `w` and `x` mean on a directory? What do `644`, `755` and `1777` allow? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
