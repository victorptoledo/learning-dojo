# Checkpoint 2: Intermediate

This checkpoint closes the **Intermediate** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 85%, so 7 right.
2. **The integration kata** (press **Enter**): a feedback form with custom, accessible
   validation messages, a draft kept in `localStorage`, and a JSON submission with `fetch`
   that handles success and failure.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| The DOM and events | Why `textContent`? Where does an event bubble? How does delegation find the element? Where does the focus go after a change? |
| Forms | Which input type and `autocomplete` token? Which `validity` flag? How is an error tied to its field and announced? |
| fetch and async code | Does `fetch` reject on a 500? How do you cancel, and how do you ignore a stale answer? Debounce or throttle? |
| Storage and state | Memory, URL, localStorage, IndexedDB or a cookie? What if the stored data is broken? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
