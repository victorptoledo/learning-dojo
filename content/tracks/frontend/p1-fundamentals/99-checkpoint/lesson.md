# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 85%, so 7 right.
2. **The integration kata** (press **Enter**): a product page from an empty `<body>`, with
   landmarks, a breadcrumb, a labelled form, design tokens, a dark theme and a responsive
   layout, checked by axe-core, html-validate and measurements in Chromium.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Semantic HTML | Which landmark is this? Which heading level comes next? `<a>` or `<button>`? What does this image's alt say? |
| Accessibility | Does every control have a name that contains its visible text? Can I do everything with the keyboard, and see the focus? When is ARIA needed? |
| Cascade and box model | Which declaration wins, and why? How wide is this box with border-box? Where do custom properties fit? |
| Flexbox, grid and responsive | One axis or two? What does `minmax(0, 1fr)` fix? Where do my breakpoints go, and in which unit? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
