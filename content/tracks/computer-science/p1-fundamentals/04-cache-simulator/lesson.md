# Cache Simulator

Simulate the cache you just studied: split addresses into tag, set index and offset, keep each set
in LRU order, track dirty lines for a write-back policy, and replay memory traces. At the end you
run the two matrix walks of the lesson through your cache and watch one miss once per line and the
other miss on every access. The kata is in Rust; if you have not used it before, the starter
declares every type and the tests show how each function is called. Press **Enter** to create the
kata folder and open it.
