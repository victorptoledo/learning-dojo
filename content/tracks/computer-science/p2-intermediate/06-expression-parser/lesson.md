# Expression Parser

Write the first half of every compiler: a lexer that turns text into positioned tokens, a
recursive-descent parser with one method per grammar rule that encodes precedence and
associativity, an AST printer, and an interpreter that walks the tree. Good error messages count
too: every syntax error must point at the exact token where things went wrong. The checkpoint of
this phase takes the same ideas further, to a compiler and a virtual machine. Press **Enter** to create the kata folder
and open it.
