# Your First Fitness Function

An architecture diagram says "the domain does not know the database". The code says whatever the
last person under deadline pressure made it say. In this kata you write the rule as a **test over
the compiled classes**, the way ArchUnit does it in real Java projects, watch it fail on a small
shop, and then fix the shop so the rule stays green for good. Press **Enter** to create the kata
folder and open it.
