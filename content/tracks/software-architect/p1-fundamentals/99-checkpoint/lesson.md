# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): a library loans app whose packages are named
   like a hexagon but whose dependencies point everywhere. You write the dependency rule as a
   fitness function, then give the domain its ports, take the static singletons, the console and
   the hidden clock out of the core, and wire everything in one composition root.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Modularity, Coupling and Cohesion | What does this module hide? Which way do the arrows point, and is that stable? |
| Layered Architecture | Strict or relaxed? Where is the sinkhole? By layer or by feature? |
| Break the Cycle (kata) | Which direction do I keep, and which technique removes the other? |
| Hexagonal, Onion and Clean | Which side owns the interface? What is the composition root for? |
| Your First Fitness Function (kata) | How do I turn the rule into a test that runs on every build? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
