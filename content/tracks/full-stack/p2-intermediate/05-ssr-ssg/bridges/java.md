| --- | --- |
| Thymeleaf per request | SSR |
| pages generated by a build plugin | SSG |
| `Cache-Control: s-maxage` on a Thymeleaf page | ISR-like caching at the CDN |
| Vaadin or a JS bundle | client rendering with hydration costs |
