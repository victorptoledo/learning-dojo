| Older habit | Python 3.15 |
| --- | --- |
| `class Foo(object):` | `class Foo:` |
| `def __init__(self, a, b): self.a = a; self.b = b` | `@dataclass class Foo: a: int; b: str` |
| hand-written `__repr__` and `__eq__` | generated by `@dataclass` |
| `collections.namedtuple("P", "x y")` | `@dataclass(frozen=True)` or `typing.NamedTuple` |
| `STATUS_OPEN = "open"` constants | `class Status(StrEnum)` |
| `def get_balance(self)` | `@property def balance(self)` |
| `__slots__ = ("x", "y")` by hand | `@dataclass(slots=True)` |
| `copy.copy(p)` then set a field | `dataclasses.replace(p, x=1)` / `copy.replace` |
