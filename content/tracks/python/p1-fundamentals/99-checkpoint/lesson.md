# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): a gradebook that parses lines into validated
   dataclasses, stores them in a dict, and builds averages, rankings and reports.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| Syntax and the Object Model | What does `b = a` do with a list? When is `is` right? Why `Decimal("0.1")`? |
| Collections | Which type has O(1) membership? How do you sort by count descending, then name? |
| Functions and Closures | When is a default evaluated? What does a bare `*` in a signature do? What does a closure capture? |
| Classes and Dataclasses | Why `default_factory`? What does `frozen=True` change, and how do you "modify" a frozen value? |
| Type Hints and Pydantic | Who checks a hint, and when? Why accept `Iterable` but return `list`? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
