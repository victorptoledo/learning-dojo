# Text Toolkit

Four helpers that a catalogue needs every day: a **search key** that makes look-alike text
compare equal, an ASCII **slug** for URLs, a **highlighter** for search results and a
**duration parser** for fields such as "1h 30m". Each one is a few lines once you know which
normalisation form, which regex function and which flags to use, and each has a trap that the
tests will find.

Read the statement, then write `textkit.py` and run `uv run pytest`.
