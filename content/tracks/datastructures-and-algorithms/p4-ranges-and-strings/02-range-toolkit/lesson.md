# Range Toolkit

Four answers to "combine the values between two positions": a difference array for many range
updates read once, a Fenwick tree for sums with point updates and a search by prefix, a sparse
table for O(1) minimums on a fixed array, and a segment tree for the maximum and its first
position while values change. The hidden tests use arrays of up to a million values and up to
two million queries. Press **Enter** to create the kata folder and open it.
