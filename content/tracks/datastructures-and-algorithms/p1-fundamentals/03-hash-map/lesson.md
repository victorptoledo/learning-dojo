# Hash Map

Write the hash table of the previous lesson: an array of buckets, a chain of entries in each,
`hashCode` to pick the bucket, `equals` to find the key, and a resize that doubles the buckets
at a load factor of 0.75. You also add the one-line trick `java.util.HashMap` uses to survive
keys whose low bits are all the same. Press **Enter** to create the kata folder and open it.
