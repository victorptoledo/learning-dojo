# Sequence Toolkit

Six classic problems on arrays and strings, each with an easy quadratic answer and a linear one.
The visible tests check small examples; the hidden tests use 200,000 elements and a time limit,
so only the linear answers pass. You practise two pointers, a sliding window, a monotonic stack,
bracket matching with a stack, and prefix sums with a hash map. Press **Enter** to create the
kata folder and open it.
