# Autocomplete

Build the trie behind a search box: words with frequencies, prefix counts that cost only the
length of the prefix, the top-k suggestions for what the user has typed so far, and removal that
prunes the branches no word needs any more. The hidden tests store 200,000 words and run 300,000
queries, so scanning a list of words is not an option. Press **Enter** to create the kata folder
and open it.
