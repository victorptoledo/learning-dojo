# DP Toolkit

Six dynamic programming classics, from a two-dimensional grid to a one-dimensional table and the
O(n log n) longest increasing subsequence. Each one rewards the same routine: write the
recursion, name the state, count the states, then fill a table in an order where every state's
inputs are ready. The hidden tests use grids of 1,500 × 1,500, strings of 3,000 characters,
200,000 values and amounts up to a million. Press **Enter** to create the kata folder and open
it.
