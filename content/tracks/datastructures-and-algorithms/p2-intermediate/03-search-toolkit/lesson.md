# Search Toolkit

Put the last two lessons to work: three binary searches (a lower bound, a rotated array and a
search on the answer), quickselect with a three-way partition, inversion counting with merge
sort, and combinations by backtracking. The hidden tests include the inputs that break the
naive versions: sorted arrays for a first-element pivot, a single repeated value for a two-way
partition, and huge ranges for a linear search over answers. Press **Enter** to create the kata
folder and open it.
