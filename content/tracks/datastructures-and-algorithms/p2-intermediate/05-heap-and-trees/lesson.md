# Heap and Trees

Write the binary heap behind `PriorityQueue`, with the bottom-up heapify that builds one in O(n),
and use it for the two classic heap problems: the k largest values and merging k sorted arrays.
Then solve binary tree problems (BST validation, k-th smallest, level order, building a balanced
tree, lowest common ancestor) on trees deep enough to overflow a recursive solution. Press
**Enter** to create the kata folder and open it.
