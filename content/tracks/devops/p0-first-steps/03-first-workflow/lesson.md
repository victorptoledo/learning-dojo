# Your First CI Workflow

Time to automate: write the GitHub Actions workflow that vets and tests a Go service on every
push to `main` and every pull request. Press **Enter** to create the kata folder and open it,
edit `.github/workflows/ci.yml` and save. The dojo checks the workflow with actionlint and
reads it with bats; nothing runs on GitHub. If the folder is a GitHub repository of yours,
push it and watch the run in the **Actions** tab too.
