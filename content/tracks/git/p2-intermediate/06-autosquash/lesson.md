# Tidy a Branch: Folding Fixup Commits Automatically

Review fixes arrive as `fixup!` commits; before the branch is merged they must disappear into
the commits they fix. Here you write the command a team would put in a script or an alias.
Press **Enter** to create the kata folder and open it.

The trick is that an "interactive" rebase only needs an editor to show you the todo list.
Give Git an editor that accepts the list unchanged and the rebase runs on its own.
