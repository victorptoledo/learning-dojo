# Checkpoint 1: Fundamentals

This checkpoint closes the **Fundamentals** phase. It has two parts, and you need both:

1. **The quiz** (press **Q**): eight questions over the whole phase. You need 7 right.
2. **The integration kata** (press **Enter**): a report of how every branch stands against
   `main`, computed from the commit graph.

Do them in any order. Before you start, review:

| Lesson | Ask yourself |
| --- | --- |
| The Object Model | What do a blob, a tree and a commit store? Why does changing an old commit change every later hash? |
| The Index and Commits | What is the difference between `git diff` and `git diff --staged`? When does `.gitignore` not help? |
| Branches and Merging | What moves when you commit? When is a merge a fast-forward? What is the merge base? |
| Undoing Changes | What do `reset --soft`, `--mixed` and `--hard` change? Why `revert` on shared history? |

> [!TIP]
> If a quiz question surprises you, open the lesson it comes from again before retrying. The
> explanation after each answer says which idea it tests.
