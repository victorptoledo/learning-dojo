# First Repository: Your First Git Kata

Your first git kata: a script that creates a ready-to-use repository. Press **Enter** to
create the kata folder and open it, edit `newrepo.sh`, and save: the tests run by themselves.

Git katas are bash scripts. The tests build repositories in a temporary folder, run your
script and then ask Git what happened (`git log`, `git ls-files`, `git status`), so you can
try every step by hand in a terminal before you write it down.
